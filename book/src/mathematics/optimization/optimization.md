# Optimization Problems

## Strategy

- draw a picture
- label constants
- label variables
- write the equation to be maximized or minimized
  - note it will frequently have two variables on the right side
- you may be able to write a second equation linking the right-hand side variables
- solve equation for one of the variables
  - sub this solution back into the original function 
- take the derivative to be max/min'd and set the derivative equal to 0 to find the max/min values
- be sure you completely answered the question

## Example -- Classic Box Problem

- might be useful $y = \frac{-b (+/-)\sqrt{b^2 - 4ac}}{2a}$
- draw a rectangle, label the length and width
- denote squares to be cut out of the corners with side-length x
- optimize the volume of the box if the edges are folded
