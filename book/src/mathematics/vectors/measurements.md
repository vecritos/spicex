# Measurements with Vectors

## Distance Between Points

$d = \sqrt{(x_2-x_1)^2 + (y_2-y_1)^2 + (z_2-z_1)^2}$

## Equation of Sphere

$(x-x_0)^2 + (y-y_0)^2 + (z-z_0)^2 = r^2$

## Angle Between Vectors

$\cos\theta = \frac{\vec{u}\cdot\vec{v}}{\|\vec{u}\|\|\vec{v}\|}$

so

$\vec{u}\cdot\vec{v} = \|\vec{u}\|\|\vec{v}\|\cos\theta$

so

$\vec{u}\cdot\vec{v}=0 \Longleftrightarrow \vec{u}\perp\vec{v}$

## Direction Cosines

$\cos\alpha = \frac{v_1}{\|\vec{v}\|}$

$\cos\beta = \frac{v_2}{\|\vec{v}\|}$

$\cos\gamma = \frac{v_3}{\|\vec{v}\|}$

## Projection of $\vec{u}$ onto $\vec{v}$

$\operatorname{proj}_{\vec{v}}\vec{u}
=
\left(\frac{\vec{u}\cdot\vec{v}}{\|\vec{v}\|^2}\right)\vec{v}$

$=
\frac{\vec{u}\cdot\vec{v}}{\|\vec{v}\|}
\frac{\vec{v}}{\|\vec{v}\|}$

$=
\|\vec{u}\|\cos\theta
\frac{\vec{v}}{\|\vec{v}\|}
=
\vec{w}_1$

## Vector Component of $\vec{u}$ Orthogonal to $\vec{v}$

$\vec{w}_2 = \vec{u} - \vec{w}_1$
