# L'Hopital's Rule

if $f(a)=g(a)=0, f'(a) \land g'(a) exist \land g'(a) \ne 0$

$\implies$

$\lim_{x \to a}\frac{f(x)}{g(x)} = \frac{f'(a)}{g'(a)}$

## Strong Form

if $f(a)=g(a)=0 \land g'(x)\ne 0$ 

$\implies$

$\lim_{x \to a}\frac{f(x)}{g(x)} = lim_{x \to a}\frac{f'(x)}{g'(x)}$

## Indeterminate Forms

$\frac{\infty}{\infty}, \infty * 0, \infty - \infty$
