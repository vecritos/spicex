# Differentials

differentials are a method of estimating changes in the value of a function based on changes in the input variable

think: $\frac{\delta y}{\delta x}$ as $\frac{\Delta y}{\Delta}x$

this implies $\delta y = f'(x)\delta x$ that is the $change in y = derivative * change in x$

if $x$ changes from $a$ to $a+\delta x$ then $df = f'(a)dx$ estimates the change in f

## Example

estimate the percent change in volume of a sphere when radius increases by 10%, **note** because $\frac{\delta V}{V}$ is a percent change divide each side by $V$ when calculating the estimated change (answer: 30%)
