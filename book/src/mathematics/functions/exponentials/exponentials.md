# Exponentials

exponential change means $y$ changes proportionally to the current value of $y$ that is $\frac{\delta y}{\delta x} = ky$ for some constant $k$ we solve by seperation of variables

$\frac{\delta y}{y} = k\delta t$

and so 

$ln\lvert y \rvert = kt + c$

and solving 

$y = e^{kt+c} = e^{c}e^{kt} = ae^{kt} = y_0 e^{kt} \implies A = pe^{rt}$
