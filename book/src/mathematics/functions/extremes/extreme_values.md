# Extreme Values on a Closed Interval

## Absolute Extremes

$f(c)$ is an absolute maximum $\iff$ $f(c) \ge f(x) \forall x \in Domain$
$f(c)$ is an absolute minimum $\iff$ $f(c) \le f(x) \forall x \in Domain$

## Extreme Value Theorem

If $f$ is continuous on a closed interval $[a,b]$ then $f$ has both maximum and minimum value on $[a,b]$

## Local Extremes

If $f$ has a local max or min at an interior point $c$ and if $f'(c)$ exists then $f'(c)=0$

## Critical Points

A point $c$ in the interior of a function is a critical point if $f'(c)=0$ or $f'(c)$ does not exist. If $f(x)$ is continuous on $[a,b]$, then the extreme values must occur at critical points or end points.
