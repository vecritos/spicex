# Derivative Tests (using the slope of the tangent to tell a story)

given critical point $c$ within the domain of $[a,b]$ for function $f$

## First Derivative Test

$f'$ changes from positive to negative $\implies$ local maximum. $f'$ changes negative to positive implies local minimum. If $f'$ does not change $\implies$ no local extrema. If at an endpoint $a$ then if $f' \lt 0$ $\implies$ local max and if $f' \gt 0$ $\implies$ local minimum; the reverse is true for the right endpoint $b$.

## Second Derivative Test

$f(c)$ is a local maximum if $f'(c)=0 and f"(c) \lt 0$ as it is concave down. $f(c)$ is a local minimum if $f'(c)=0 and f"(c) \gt 0$ as it is concave up.
