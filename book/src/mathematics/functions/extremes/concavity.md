# Concavity

$f(x)$ is concave up on $(a,b)$ if $f'(x)$ is increasing on $(a,b)$. $f(x)$ is concave down on $(a,b)$ if $f'(x)$ is decreasing $\therefore$ $f(x)$ is concave up when $f"(x) \gt 0$ and concave down when $f"(x) \lt 0$. Inflection points are where to concavity changes, therefore where $f"(x)$ changes sign.
