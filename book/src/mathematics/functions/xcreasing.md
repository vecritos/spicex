# (In|De)creasing Functions

let $f$ be defined on an internal $I$ and $x_1, x_2$ be any two points in $I$. $f$ increases on $I$ if $x_1 \lt x_2 \implies f(x_1) \lt f(x_2)$. $f$ decreases on $I$ if $x_1 \lt x_2 \implies f(x_1) \gt f(x_2)$. A function that always increases or decreases on $I$ is monotonic there. 

## Using Tangent Lines

let $f$ be continuous on $[a,b]$ and differentiable on $(a,b)$ if $f'(0) \gt 0 on (a,b) \implies f increases \in [a,b]$. Secondly, if $f'(0) \lt 0 on (a,b) \implies f decreases on [a,b]$
