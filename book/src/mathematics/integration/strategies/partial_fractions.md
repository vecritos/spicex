# Partial Fractions

partial fractions is a technique in which rational expressions are split into the sum of fractions with linear denominators

## Example

$\frac{x+5}{x^2-x-6} = \frac{A}{x-3}+\frac{B}{x+2}$

so

$x+5 = A(x+2)+B(x-3)$

pick values for $x$ that cancel one of the terms, because it must be true for all $x$ then solve for either $A$ or $B$
