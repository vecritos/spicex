# The Fundamental Theorem of Integral Calculus

## Part 1

if $f(t)$ is a continuous function on $[a,b]$ and $F(x)=\int_{a}^{x}{f(t)\delta t}$ $\implies$ $F(x)$ is differentiable on $[a,b]$ and $F'(x) = \frac{\delta(\int_{a}^{x}{f(t)\delta t})}{\delta x} = f(x)$

## Part 2

If $f(x)$ is continuous on $[a,b]$ then $\int_{a}^{b}{f(x)\delta x} = F(b)-F(a)$ where $F(x)$ is any antiderivative of $f(x)$

consequences include displacement (s) *or a more generic form of change in parent function*

$s(b) = s(a)+\int_{a}^{b}{v(t)\delta t}$
