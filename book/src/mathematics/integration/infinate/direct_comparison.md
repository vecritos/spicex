# Direct Comparison Test

let $f$ and $g$ be continous on $[a, \infty)$ and $0 \le f(x) \le g(x) \forall x \ge a$ 

$\implies$

1) $\int_{a}^{\infty}{f(x)\delta x}$ converges if $g(x)$ converges. less than finite is finite.

2) $\int_{a}^{\infty}{g(x)\delta x}$ diverges if $f(x)$ diverges. more than infinate is infinate.
