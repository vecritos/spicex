# Solids of Revolution

## Volume

if a solid has known integrable cross sections of $A(x)$ then the volume from $x=a \to x=b$ is $V=\int_{a}^{b}A(x)\delta x$

## Surface Area

find the surface area of the solid generated by revolving $f(x)$ on $[a,b]$ about the x-axis. means that we partition the x-axis. each horizontal $\delta x$ defines a slightly longer corresponding arc when the arc is revolved it creates a ribbon of area; each ribbon is actually a rectangle. 

so for a circular (vase shape)

$A = \int_{a}^{b}{2\pi r\sqrt{1 + (\frac{\delta y}{\delta x})^2}}$


## washers
