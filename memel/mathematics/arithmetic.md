# Arithmetic Sequences

## Nth-Term Explicit

$a_n = a_1 + (n-1)\delta$

## Nth-Term Recursive

$$
a(x) = 
\begin{cases} 
a_1 = ? & \text{if } n = 1 \\
a_n = a_(n-1) + \delta & \text{if } n \gt 1 
\end{cases}
$$

## Arithmetic Series Partial Sums

- $S_n = (n/2)(a_1 + a_n)$
- $S_n = (n/2)(2*a_1 + (n-1)\delta)$
