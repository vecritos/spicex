wraps an object and provices a different interface to it: facade, simplification
subclasses decide how to implement steps in an algorithm: template method, structure
subclasses decide which concrete class to create: factory method, creation
ensures one and only object is created: singleton, access
encapsulated interchangeable behaviors and uses delegation to decide which one to use: strategy, interchangeable
clients treat collections of objects and individual objects uniformly: composite, uniformity
encapsulates state based behavriors and uses delegation to switch between behaviors: state, internals
provides a way to traverse a collection of objects without exposing its implementation: iterator, traversal
simplifies the interface of a set of classes: adapter, combineability
wraps an object to provide new behavior: decorator, extension
allows a client to create families of objects without specifying their concrete class: abstract factory, combination
allows objects to be notified when state changes: observer, updates
wraps an object to control access to it: proxy, control
encapsulates a request as an object: command, request
