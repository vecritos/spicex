# Trigonometry (trig)

## Uni the Unit Circle Breakdown

function | sides (w/ right triangle)
---|---
sin | $sin(\theta) = opp/hyp$
cos | $cos(\theta) = adj/hyp$
tan | $sin(\theta)/cos(\theta) = opp/adj$
csc | $csc(\theta) = 1/sin(\theta) = hyp/opp$
sec | $sec(\theta) = 1/cos(\theta) = hyp/agj$
cot | $cot(\theta) = 1/tan(\theta) = adj/opp$

## Trigonometric Identities

- $tan(\theta) = {sin(\theta)} / cos(\theta)$
- $csc(\theta) = 1 / { sin(\theta) }$
- $sec(\theta) = 1 over { cos(\theta) }$
- $cot(\theta) = { cos(\theta) } / { sin(\theta) }$
- $cos(\alpha (+/-) \beta) = cos(\alpha)cos(\beta)(-+)sin(\alpha)sin(\beta)$
- $sin(\alpha(+-)\beta) = sin(\alpha)cos(\beta)(+-)cos(\alpha)sin(\beta)$
- $cos(2x) = (cos^2(x) - sin^2(x)) = (2cos^2(x) - 1) = (1-2sin^2(x))$
- $sin^2(x / 2) = { 1 - cos(x) } / 2 $
- $cos^2(x / 2) = { 1 + cos(x) } / 2 $

### Pythagorean Identities

- $sin^2(x) + cos^2(x) = 1 $
- $tan^2(x) + 1 = sec^2(x)$
- $1 + cot^2(x) = csc^2(x)$
