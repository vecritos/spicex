# Watney

A collection of material for inclusion in the book I'm working on. It includes:

- Some helpful programs for file modification that I've needed on my journey
- Examples of scripts that can be run for things like home servers, and firewall setups (simplified to concepts)
- A collection of adhoc ideas for designing fun materials in various skillsets
- A formatted markdown book which will be the basis I will build upon
- A consolidation of the research results from equipment design and inclusion
- Other clippings, ideas, and inserts that I will either include or nix from the book itself

It is being worked on at this moment open source, however I am not being paid nor do I ~expect~ to make money,
any pseudo-advertisements are my own words there's no paid sponsorship or otherwise.

This readme may become less relevant as the project evolves so it's been updated at the start of Sep 2026 and we'll see.
