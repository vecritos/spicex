## Preliminary v6 Digitization Problems to solve

> **NOTE** some of these considerations are for necessary durability and full armour requirements.
> **NOTE** Digitization can work in hand with durability layers, a system-layered-approach is better than a single unit.
> **NOTE** A non-exhaustive non-demanding list of possible inclusions on the digital layer

- digitization (mentioned before but not necessarily it's own layer)
  - make sure to allow for programmability, i don't want to input everything on the system itself, allow for hier-menu based modification from linked computer
  - air filtering
    - breathing can spin micro-fans to re-harness energy from the wind flow of breathing
      - things like air chemical breakdown scanners can be powered off of this
  - wrist
    - health monitoring (heart rate, oxygen,..)
    - gps (transmit, previous location estimate, non-transmit standby, off)
  - battery operation
    - steppers (electromagnetic induction technology)
      - these harness energy on each step, i'd put them in the leg and back area to maximize vertical throw of each step rotation
        - by attaching to springs you can get reasonable return for both lift and impact during your stride
    - try to keep digitization efficient enough so 15 minutes of jumping jacks reasonably charges essential components
      - this is a made up number but a baseline should be established
  - gyroscope-capable glove, when enabled allows non-verbal communications or relays
    - macros can be preprogrammed to give hand signals different implementations
      - keep theme of each the same for example "launch allowed" versus "launch initiated" 
    - touch pads can be added to a thin liner glove for keyboard style finger inputs
      - durability glove should be built to cover this for gardening or other activities
    - Some basic responses can be hard buttons with single-handed input system
      - as in confirmation can be thumb to fore-finger.
        - optionally trigger a response based on most or least tendon-tension to allow quick non-press responses
  - external displays 
    - extremely important to allow third party programming as to permit prototyping of display information
    - important to allow hard wire switch for off position as these are beacons at night
    - thigh
      - works for sitting positions like flight planning or documentation
        - bigger screen size allows for more information
        - location disallows practical use when standing 
      - useful for insignia or relative mission information when standing 
    - forearms can be used to track positioning or input basic beck-and-call commands
      - possible to have satellite information relayed over localized wireless for stationary observation
      - possible to outline location coordinates for a drone to fly in coordinated rotations
      - other ideas are possible, but i like forearm better for navigational and location-specific information
    - thumb connection
      - smartwatch sized and relocated to that position for viewing when prone or at computer 
      - useful for as needed requests or notifications
      - useful for semi-heads up display for relevant information, think consistent monitoring
  - heads up displays useful
    - pair in micro-technology in helm wired into things like smart glasses (i think google glasses is the only market product i know about)
    - audio inputs are essential but allow hardwired into rest of suit, run plugin down the back
    - add switches or input buttons to under chin, temple, ear, chin locations
      - feel free to add an array of buttons to chin-scape, multiple on side of chin, one under chin to unlock buttons
        - this allows for more complex 4bit inputs with a submission button
    - for high-intensity environments where non-planned facial gestures are expected avoid eye-movement inputs
      - this could be toggle-able
        - if included things like far-distance viewing can be `squint -> zoom on location -> open -> stop zoom -> blink twice -> return to 0 zoom`
  - extendable antenna for radio communications equipment
    - the first thing to go wrong is usually communication and communication systems
    - could be possible to use deployable wire cords or collapsible radio-frames for extended use in one location
      - these can be stored slung on the back like a bow might be if we were hunting, smaller ones could be stored on the legs
  - internal cable runs with intermixed components, no external wiring for included components
    - leave a generic plug-in or two for external data access, think plugging your phone in while it's still in your pocket
  - Move main wiring off hip and into back seam, heavy packs with hip belts will conflate, design appropriately 
  - Additional battery mounts left open to calculation of minimum energy swings, avoid ankle battery packs
