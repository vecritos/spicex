## AI Assistance

This project was developed with occasional assistance from AI tools used for technical discussion, research, and reference examples.

**Tools:** ChatGPT-{4|5.3|5-mini}, Gemini, CoPilot
**Provider:** OpenAI, Google, Microsoft

AI assistance was used for:
- brainstorming architecture and system design
- discussing implementation strategies
- generating example code snippets for reference

All final design decisions, architecture, and implementation were created and maintained by the project author. AI was used interactively as a conversational technical reference and brainstorming tool during development.

Additional models may be consulted in the future as the project evolves.
