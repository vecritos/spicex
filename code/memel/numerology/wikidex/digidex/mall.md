## explanations

decision trees -- interpretable categorized enumerations flagging important features, useful in understanding logical statements 
naive bayes -- independence assumed, simple, fast, capable of processing many features on immediacy request 
k-nearest neighbors (knn) -- intuative [distance] based metrics easily visualized
support vector machines (svm) -- non-linear kernel tricks moving across higher dimensional data with high accuracy [? accuracy of precesions]
forest -- cluster of decision tress to increase generalization with lower overfitting problems (useful in unsupervised consolodation pattern formation tactics)
gradient boosting -- regressional classification, useful to bucket categorization and aquire more boosted buckets as gradients fill buckets with next unsupervised pattern to match
